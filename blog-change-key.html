How to change the key of a song without changing its speed

Singers move songs into a key that fits their voice. Players slow down a fast solo to learn it. Both jobs need the same thing: changing pitch and speed separately. Here is how to do it.

Change the key

Open the Pitch and speed changer and drop in your file. Move the Pitch slider by semitones. Each step is one note on a piano, so minus two takes a song in D down to C. The speed stays the same. Use the fine tune box if a recording is slightly off from standard tuning, where 100 cents make one semitone.

Slow a song down to learn it

Press the Practice at 75 percent preset, or set the Speed slider yourself. The pitch stays where it was, so the song still sounds like itself, only slower. Tick Loop a section, enter the start and end in seconds, and the tricky bar repeats until you have it.

Which direction sounds better

Small changes of one to three semitones sound the most natural. Large changes can add a slight warble, because the tool is stretching the sound and then resampling it. Moving down usually hides this better than moving up. If you are changing the key for a mix, the Camelot wheel guide explains which keys sit well together.

Tape mode

Tick Tape mode and speed and pitch move together, like a record. That is the effect used in slowed and reverb edits.

Save the result

Pick MP3 or WAV and press Save. The file name records the speed and the number of semitones, so you can keep several versions apart.
