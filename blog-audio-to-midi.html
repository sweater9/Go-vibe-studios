How to turn a melody into MIDI for free

Hum a tune, whistle it or play it on a single line instrument, and get the notes as a MIDI file you can open in any music program. The work happens in your browser, so your recording never leaves your device.

What it can and cannot do

The Audio to MIDI tool follows one note at a time. It works well on a voice, a whistle, a bass line or a lead melody. It does not work on chords or on a full song with drums and many instruments, because it cannot tell which note belongs to which sound.

Record something clean

Record in a quiet room, close to the microphone, and sing or play one note at a time with a small gap between notes. If the file has background noise, clean it first with the audio cleanup tool. The Recorder can make the recording.

Find the notes

Drop the file in, choose what kind of sound it is, and press Find the notes. A voice or whistle, a high lead and a bass each use a different pitch range, which helps avoid mistakes. You see the notes drawn on a piano roll and can play them back to check.

Set the tempo

Type the tempo you were playing to, so the notes line up with the bars when you open the file. If you do not know it, find it with the BPM and key finder.

Use the MIDI file

Save the file and open it in the Studio or any other music program, then choose a new sound for the melody. Treat it as a first draft. If a note is missing or wrong, fix it in the piano roll.
